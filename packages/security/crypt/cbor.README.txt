CBOR (Concise Binary Object Representation) for Java
====================================================

Used by FarCry Core's WebAuthn / FIDO2 second-factor support (see
docs/0014-clientud-multi-factor-authentication.md) to decode attestation
objects and COSE public keys during passkey registration. All protocol
verification (signatures, challenge, origin, rpId, sign counter) is done with
the JVM's own crypto (java.security); this library is used only for the CBOR
decoding step.

Author: Peter Occil. Public-domain dedications, both compatible with FarCry
Core's GPL v3 (or later) licence:
  - cbor 4.5.6 is released under the Unlicense (see cbor.LICENSE.txt).
  - numbers 1.8.2 and datautilities 1.1.0 are released under CC0 1.0 Universal
    (see cbor.deps.LICENSE.txt).
Both are public-domain-equivalent and place no conditions on use.

this.javaSettings.loadPaths (the same mechanism as jbcrypt / scrypt), on both
Lucee and Adobe ColdFusion, with graceful degradation when absent.
